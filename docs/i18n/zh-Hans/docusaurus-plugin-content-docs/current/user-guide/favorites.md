# 收藏夹

收藏夹让您可以将最常访问的集群、Namespace 和单个资源加入书签。它们会显示在侧边栏中，方便您在仪表板的任意位置一键直达。

## 添加收藏

可以从以下三个位置收藏任意条目：

| 位置 | 收藏方式 |
|----------|----------------|
| **侧边栏的集群 / Namespace** | 将鼠标悬停在名称上，点击星标图标 |
| **资源列表行** | 点击行操作列中的星标图标 |
| **资源详情页** | 点击页面标题区域中的星标图标 |

实心黄色星标表示该条目已被收藏。

## 访问收藏夹

收藏夹显示在侧边栏顶部的 **Starred** 区域，位于完整资源树的上方。点击收藏条目可直接跳转到：

- **集群** → 切换到该活跃集群并进入集群概览页
- **Namespace** → 切换到该 Namespace 并打开 Pod 列表
- **资源** → 直接打开资源详情页

## 收藏夹排序

在侧边栏中拖拽收藏条目可自定义排列顺序，顺序会即时保存。

:::tip
将最关键的 Deployment 置于收藏列表顶部，这样在发生故障时始终可以一键访问。
:::

## 管理所有收藏

1. 点击 Starred 区域底部的 **Starred → Manage**，或进入 **Settings → Favorites**
2. 管理页面以表格形式展示所有收藏，包含集群、Namespace、资源类型和名称信息
3. 拖拽以重新排序，或点击任意行的 **Remove** 取消收藏

## 按用户存储

收藏夹按用户存储在 KubeVision 数据库中，而非浏览器本地。这意味着使用同一账户登录时，您的收藏夹可以跨浏览器和设备同步。

:::info
收藏夹是个人私有的，不会在用户之间共享，也不会出现在其他用户的仪表板中。
:::

## 资源被删除后的处理

如果已收藏的资源从 Kubernetes 中删除，侧边栏条目会显示 **Not Found** 徽标。您可以在管理页面或通过再次点击星标来将其从收藏夹中移除。
