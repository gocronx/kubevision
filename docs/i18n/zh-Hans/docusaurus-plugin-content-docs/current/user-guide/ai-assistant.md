# AI 助手

AI 助手可以在控制台中检查用户有权访问的 Kubernetes 状态、解释故障、汇总
日志、生成资源清单并提出运维操作。它可以作为侧边栏使用，也可以切换为占满
当前 Tab 的对话工作区。

## 配置提供商

打开**设置 > AI 助手**。管理员可以选择支持的提供商，填写端点和凭据，获取
模型列表并测试配置。凭据会加密保存，API 保存后不会再返回明文。

只应配置可信服务。对话中包含的资源详情和日志片段会发送给该提供商。集群数据
必须留在内网时，可以使用本地 OpenAI 兼容端点。

## 工具操作

读取操作只能访问当前用户有权查看的资源。修改工具使用与普通界面相同的 RBAC，
并在执行前暂停，等待用户明确确认。确认前应检查目标集群、命名空间、资源和生成
参数。

复杂请求可能包含多个连续的 Kubernetes 步骤。应保持对话打开，直到助手报告
完成或明确错误；中断确认流程或认证过期都可能使执行停止。

## 显示模式

使用助手中的布局控件在侧边栏和完整 Tab 之间切换，切换时会保留对话。完整 Tab
适合长时间排障，侧边栏则便于边查看当前资源边交流。
